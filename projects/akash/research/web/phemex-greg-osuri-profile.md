## Akash's AI pivot — chronological

- 2022–2023: CPU-focused VPS competitor
- **2023**: NVIDIA H100 support added
- **2024**: L40S and A100 inventory expanded
- **Late 2025**: NVIDIA Blackwell B200/B300 architecture integration
- **November 2025**: AkashML launched (serverless AI inference layer)
- 70-85% cheaper than AWS SageMaker / OpenAI hosted endpoints

## Akash positioning vs hyperscalers

- AWS / Azure / Google Cloud have **locked up early Blackwell supply**
- Akash offers second-source access through decentralized provider network
- For inference workloads: increasingly competitive on cost
- For training workloads: hyperscalers still hold large clusters; gap is
  narrower but real
