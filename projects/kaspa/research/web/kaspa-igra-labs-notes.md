# Igra Labs L2 - Kaspa Notes summary

Source: https://kaspanotes.com/ecosystem/l2/igra-labs
Scraped: 2026-05-27

## Overview

- **Based rollup** leveraging Kaspa L1 for sequencing
- Igra nodes store data back to **genesis of the L2 network**
- **EVM compatible**
- **Launched in early 2026**

## Investor takeaways

- Igra is the first major Kaspa L2 with EVM compatibility, providing a path for existing Solidity developers to deploy on Kaspa security
- Safe Wallet support is meaningful: institutional treasuries that already use Safe on Ethereum can extend to Igra
- Single-DEX dependence (Zealous Swap as both market venue and IGRA auction operator) is a concentration risk to flag
- Community-maintained notes site rather than primary source - cross-check with igralabs.com directly
