## Headline framing

- Tagline: "Internet-scale machine learning"
- Bittensor = "a language for writing numerous decentralized commodity markets,
  or 'subnets', situated under a unified token system"
- Analogy: "Bittensor brings the same type of abstraction which Ethereum added
  to Bitcoin for running decentralized contracts, but onto Bitcoin's inverse
  innovation — digital markets"
- TAO described as the "mycelial network connecting humanity with the future of
  Artificial Intelligence"

## Architecture claims

- Bittensor as **language for writing markets**: storage, compute, intelligence,
  oracles, data procurement — all in one ecosystem
- Native token TAO: "transferrable and censorship resistant"
- Substrate blockchain (Polkadot)
- **Yuma Consensus (YC)** = "central processing unit of Bittensor": agnostic to
  what is being measured, "allows for fuzzy consensus around probabilistic
  truths — truths like intelligence"
- Key innovation: separation of chain core (transferring funds) from validation
  systems for commodity creation — validators can run off-chain, in any language
  (Rust/Python/C++), with heavy compute and data
- Subnet 1 example: intelligence providers validated against ML models;
  validation can adapt and learn without information moving on-chain
